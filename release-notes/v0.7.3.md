# v0.7.3 — Automatic Inline Pasted Screenshots (`hostedContents`), Viewport Thumbnails & One-Click / `Alt+v` HD Preview

Version `0.7.3` brings full end-to-end parity for pasted inline Teams screenshots (`hostedContents`) across the TUI, CLI, HTTP API, and MCP server, alongside viewport-driven inline thumbnails and instant one-click or `Alt+v` high-resolution previewing.

## Automatic Inline Pasted Image (`hostedContents`) Support

- **Seamless Inline Screenshot Synthesis**: Automatically synthesizes image `AttachmentInfo` entries (`hosted:<id>`) for `<img src=".../hostedContents/.../$value">` screenshots pasted directly into Teams chats and channels — both on fresh Microsoft Graph syncs and dynamically via `MessageItem::effective_attachments()` for pre-existing local SQLite caches.
- **Clean Emoji Rendering**: Recognizes Teams `<emoji>` elements and `itemtype*="Emoji"` CDN sprites so inline emojis render cleanly as Unicode characters (`🚀`, `👍`) instead of spurious `[IMG #1]` attachment chips.

## Viewport-Driven Chat & Thread Thumbnails + One-Click / `Alt+v` HD Preview

- **Scroll-Aware Thumbnail Prefetch**: Automatically prefetches inline image thumbnails for the active scroll viewport across full message history in both the main Chat stream and Thread drawers at any scroll offset.
- **One-Click & Composer `Alt+v` Preview**: Left-clicking `[IMG ...]` chips or rendered inline thumbnails opens the high-resolution Sixel / iTerm2 / Kitty / Halfblock `ImagePreview` modal directly, while global `Alt+v` lets you open HD image previews straight from the Composer without leaving your draft.

## CLI, HTTP API & MCP Inline Image Parity

- **Full Downstream Parity**: Exposes inline `hostedContents` screenshots consistently across `teams preview`, `teams download`, `teams read`, `teams export`, HTTP API attachment endpoints, and MCP tools (`get_messages`, `get_thread`, `download_attachment`), with automatic image magic-byte extension detection (`png` / `jpg` / `gif` / `webp`) when saving hosted images to disk.
