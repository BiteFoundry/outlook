## Changes

Editing a draft body preserves the quoted conversation. Folder operations recover from stale cached IDs, and recipient errors include guidance when Exchange rejects an address.

## Compatibility

## Compatibility changes

- `move --json` and `archive --json` now return `message_id` and `previous_message_id`. Scripts that read `.message` can pass `--json --full`. In MCP `update_message` and HTTP `PATCH /v1/mail/messages/{id}`, the default `moved` object contains `id` and `folder_id`. MCP callers can request the full public message with `"compact": false`.
- `calendar --json` and the `remote` results in `search --remote --json` now use compact records. Add `--full` for full records. In MCP, pass `"compact": false` to `list_events` or `search_mail`.
