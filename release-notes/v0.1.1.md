# v0.1.1 — Mail Reliability, Hierarchical Folders, Localized Mailbox & Search Fixes (`@shinick/outlook`)

Version `0.1.1` is a quality and reliability release for **`outlook`** (`@shinick/outlook`), resolving four key email viewing, folder navigation, localization, and search issues in the TUI and CLI.

## What's Fixed

- **Full Email Body Display**:
  - **Non-blocking concurrent message hydration**: Selecting an email or navigating threads hydrates full bodies concurrently in the background without blocking the UI thread, while displaying wrapped preview text and a loading indicator until hydration finishes.
  - **CJK-aware plain-text wrapping**: `wrap_plain_text_line` wraps long ASCII URLs and continuous CJK strings across display-width boundaries without dropping characters or truncating lines.
  - **Quoted-only HTML body unwrapping & blank-body safety fallback**: Messages whose primary HTML content sits inside quoted/reply wrappers are cleanly unwrapped so content remains visible, and empty or hidden-HTML bodies safely fall back to plain-text or preview rendering so bodies never appear blank.
- **Hierarchical Inbox Subfolders & Custom Folder Trees**:
  - **Recursive subfolder discovery**: Folder synchronization recursively fetches `/childFolders` via Microsoft Graph `$batch` requests up to depth 6, preserving parent/child relationships.
  - **Indented folder trees**: Both Inbox subfolders and custom folders render as indented hierarchical trees in the TUI navigation pane.
  - **Full folder paths everywhere**: Folder paths (e.g., `Inbox/Projects/Q4`) are shown and searchable across the folder picker (`g`), `Ctrl+K` command palette, and `outlook folders` CLI output.
- **Sent Folder & Localized Mailbox Support**:
  - **Locale-independent well-known folder resolution**: Resolves `inbox`, `sentitems`, `drafts`, `archive`, `deleteditems`, and `junkemail` via `$batch` well-known folder ID lookup alongside Korean localized folder name aliases (`받은 편지함`, `보낸 편지함`, `임시 보관함`, etc.).
  - **Parallel Sent Items prefetch**: Bootstrap sync prefetches `sentitems` in parallel so Sent Mail is immediately populated on startup.
  - **`To:` recipient display in Sent & Drafts**: Mail list rows in Sent and Drafts folders display `To: <recipient>` with clean fallbacks rather than repeating the sender's own name.
- **Fast & Reliable Older-Mail Search**:
  - **350ms debounced remote Graph `$search`**: Typing in the search overlay (`/` or `Ctrl+F`) automatically triggers debounced remote Microsoft Graph `$search` queries after local SQLite FTS5 results appear.
  - **Selectable server-search footer row & error recovery**: Includes a selectable server-search status/trigger row in search results and clean retry/recovery handling if a remote search request fails.
  - **Pinned-mail preservation & immediate hydration**: Jumping to an older email returned by remote search preserves it via `pinned_mail` even before it enters the active folder window and triggers immediate body hydration.
