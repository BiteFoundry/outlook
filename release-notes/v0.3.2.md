## What's Changed

### Honest Compact Reads, Selective `fields` Projection & Richer Graph Metadata
- Added top-level `omitted` metadata and follow-up `hint` to compact `list_messages`, online `search_mail`, and `list_events` MCP responses so omitted fields are never mistaken for absent data.
- Added MCP `get_event` and selective `fields: [...]` projection on both `get_message` and `get_event` (with `missing_fields` reporting) so agents can fetch specific fields without pulling full HTML bodies.
- Preserved Graph mail `categories` & `sender` and calendar `categories`, `show_as`, `sensitivity`, `event_type`, `has_attachments`, `is_recurring`, and `recurrence` with backwards-compatible SQLite/JSON migrations.

### Symlinked `$HOME` & npm Postinstall Hardening
- Fixed `scripts/postinstall.mjs` main-module guard via `fs.realpathSync` for symlinked `$HOME` / npm prefixes.
- Canonicalized daemon UDS hashes and isolated `XDG_RUNTIME_DIR` fallback sockets per profile.
- Preserved dotfile symlinks in `write_atomic` (while refusing `0600` secret symlinks), expanded `~/` on `OUTLOOK_CONFIG_DIR`/`OUTLOOK_DATA_DIR`/`TEAMS_CONFIG_DIR`/`$EDITOR`, and resolved symlinked binaries in `updater.rs`.
