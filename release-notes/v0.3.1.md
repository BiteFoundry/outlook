## Changes

- **Calendar**: Graph's offset-less UTC times are normalised to RFC3339, so the TUI shows the right start and end times again, and the cached calendar is bounded to the sync window so old history no longer hides upcoming events. `create-event --all-day` sends midnight boundaries (previously a Graph 400 outside UTC).
- **Sign-in**: login, refresh and `doctor` share one scope list, which now includes `User.ReadBasic.All` for directory search. A shared `teams-cli` session that has expired or only holds Teams scopes is upgraded silently through its refresh token instead of asking you to sign in.
- **Mail folders**: a folder listing that was throttled or cut short is merged into the cache instead of replacing it, so folders are no longer dropped from the cache.
- **Bounded scans**: the first sync of a very large folder started by a listing (CLI, MCP, HTTP) stops after 40 pages and continues on the next call. HTTP filtered listings stop after 20 pages, like the CLI and MCP.
- **TUI**: archive, move and read/flag toggles are rolled back when Graph rejects them. Start-up no longer switches the list back to the Inbox, and the Focused filter applies to the first selection.
- **Multiple accounts**: each account has its own draft file (`drafts/<user>.json`). The old `drafts.json` moves to the first account that opens the TUI. A credentials file without a user id no longer opens another account's cache.
- **Corporate networks**: HTTPS now trusts the OS certificate store in addition to the bundled roots. A private root CA can be added with `OUTLOOK_EXTRA_CA_PEM` (`SSL_CERT_FILE` and `NODE_EXTRA_CA_CERTS` also work). An untrusted-certificate error says what to set, and `outlook doctor` lists the CA files it loaded. See [docs/NPM.md](../docs/NPM.md#corporate-tls-proxies-and-private-root-cas).
- **MCP**: tool descriptions state how many Graph requests a call costs and that `offline` reads only the cache. Tool names and arguments are unchanged.

## Compatibility changes

- **`outlook serve` requires a key by default.** Without `--api-key`, a loopback server generates a random Bearer token for each run and prints it to stderr.
  Migration: pass `--api-key <KEY>` for a stable key, or `--allow-keyless` to keep the old keyless behaviour on loopback.
- **`outlook serve` refuses browser origins unless they are allowed** (403, preflights included), with or without a key. Pages on `localhost` were allowed before.
  Migration: start the server with `--cors-origin http://localhost:5173` (repeatable) for each browser app.
- **A keyless `outlook serve` refuses other `Host` names** (403) than `localhost`, `127.0.0.1` and `[::1]`.
  Migration: list extra names in `OUTLOOK_SERVE_ALLOWED_HOSTS` (comma-separated), or use `--api-key`.
- **Calendar JSON times for timed events end in `Z`** (for example `2026-11-23T09:00:00Z`). All-day events keep their date-only form.
- **`create-event --time-zone`**: wall-clock input is read in that zone, and RFC3339 input is sent as a UTC instant. `--all-day` needs `YYYY-MM-DD` for `--start` and `--end`, with an exclusive end date.
- **Directory search needs `User.ReadBasic.All`.** Existing sessions keep working without it; run `outlook login` once to get directory results. `outlook doctor` lists `missing_scopes`. In tenants that restrict user consent, this scope may need admin approval; until then, set `scopes = [...]` in `config.toml` without it.
- **Listings can return a partial first sync**: CLI, MCP and HTTP mail listings may report `"sync_complete": false` while a large folder is still syncing, and HTTP filtered listings report `has_more` after 20 pages.
