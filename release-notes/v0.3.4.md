## What's Changed

### Sync & Graph Latency Optimization
- Eliminated the duplicate `/me` round-trip on bootstrap (`bootstrap_outlook_with_profile`) and overlapped Wave 2 mail/calendar/To Do/contacts sync via `tokio::join!`.
- Replaced the 5–8 stage serial waterfall in `run_bootstrap_core` / `run_refresh_all_and_emit` with 6 concurrent domain branches and eliminated duplicate `/me/todo/lists` requests.
- Unblocked Lane 1 interactive commands during multi-page folder deltas and `LoadOlderMail` via bounded spawned tasks (`Semaphore(4)`).
- Overlapped Lane 2 slow-tick domains (Calendar, To Do, Contacts) and warm-cache folder+inbox polling, plus `cmd_sync` inbox delta and To Do list task syncing.
- Memoized unsupported `POST /$batch` (404/405) and `/users?$search` (400/501) per `GraphClient`, parallelized fallback folder/message fetches (`buffered(4)`), and combined `isRead` + `flag` updates into a single `PATCH`.

### TUI Navigation & Draft Responsiveness
- Added bounded, deduplicated interactive adjacent message body prefetching (`SyncCommand::PrefetchMessages`) on TUI row/folder selection.
- Eliminated the trailing `GET` before draft send and updated `UiMsg::MailDraftSaved` to refresh Drafts and detail cache immediately without a reload flash.

### Test Hardening
- Guarded unit-test config and draft persistence from mutating the host user config directory and aligned the compact `search_mail` e2e metadata assertion.
