# v0.5.0 — Ultra-Light Native Architecture, Header-First Outlook, 0ms Optimistic UI & Shared Sync Daemon

Version `0.5.0` completes the end-to-end lightweight architecture across `teams`, `outlook`, and `onenote` — cutting startup latency to milliseconds, eliminating multi-megabyte background HTML downloads, removing the idle Node.js wrapper process on npm installs, adding Superhuman-grade 0ms Optimistic UI, and introducing an optional single-instance background sync daemon (`teams daemon` / `outlook daemon`).

## Priority 1 — Zero-Overhead Startup, Header-First Outlook & Direct Native Binary Execution

- **Header-First / Lazy-Body Outlook Sync**: Splits Graph mail `$select` into lightweight header fields (`MAIL_HEADER_SELECT_FIELDS`, omitting `body`) for folder listing, delta sync, and remote search — cutting periodic mail payload sizes by >90% and eliminating background HTML DOM parsing across 40–100 inbox items. Full HTML bodies are fetched on demand (`get_mail_message` + `$batch` `batch_get_mail_messages` neighbor prefetch) while preserving cached full bodies and `mail_fts` search entries in SQLite (`list_mail_summaries`).
- **Incremental Delta Polling & Domain Gating**: Switches periodic Outlook background ticks to incremental `delta_mail_messages` + Calendar `delta_calendar_view` with 10-minute TTL gating on slow endpoints, lock-free per-persona active domain gating (`TEAMS_BACKGROUND_ALL=1` override), and 1x / 4x / 10x adaptive idle backoff when the terminal is inactive.
- **First-Frame-First Boot & SQLite `PRAGMA user_version` Fast-Path**: Enters the alternate TUI screen immediately (<10ms), loads only the active persona's initial tab slice before drawing Frame #1, activates secondary workspaces on first tab visit, and skips ~350 lines of SQLite DDL/migration checks on warm startups via `PRAGMA user_version`.
- **Zero-Node npm Native Binary Linker (`scripts/postinstall.mjs`)**: Links prebuilt binaries directly on install (Unix hardlink/symlink replacement; Windows zero-copy NTFS hardlinks `teams.exe` / `outlook.exe` / `onenote.exe` + `.cmd`/`.ps1`/POSIX shim rewrite), eliminating ~80–120ms V8 startup latency and ~45MB idle `node` parent RSS.

## Priority 2 — 0ms Optimistic UI, Virtualized Navigation & Instant Local CLI

- **0ms Optimistic UI with Automatic Rollback**: Mail read/unread toggle, flag toggle, archive, delete, Microsoft To Do completion toggle, and Teams chat/channel message sends update `AppState` and the screen immediately (<1ms) and roll back automatically with an error toast if the background Graph request fails.
- **Zero-Allocation Navigation Pane & Mail View**: Replaces 4x per-keypress `Vec<NavRow>` deep clones with `O(1)` `nav_row_count`, a 128-bit `DualHasher` `Arc<[NavRow]>` LRU cache, `O(N)` channel unread lookup, and borrow-based `draw_mail_pane` rendering with zero `MailMessage::clone()` per frame.
- **Single-Thread CLI Fast-Path & `--cached` (`--fast`) SWR**: Runs one-shot CLI commands on a zero-worker-pool `current_thread` Tokio runtime, exits `--help`/`--version` before TLS/runtime init, and adds `--cached` (`--fast`) + `TEAMS_CLI_CACHE_SECS` local SQLite instant responses (`open_storage_only`).

## Priority 3 — Shared Background Sync Daemon & Strict Memory/RSS Hardening

- **Optional Single-Instance Sync Daemon (`teams daemon` / `outlook daemon`)**: `daemon start | stop | status | restart | run` (plus `TEAMS_AUTO_DAEMON=1` / `auto_daemon = true`) runs one ~12MB background sync process over `0600` Unix Domain Sockets (Linux/macOS) or authenticated loopback IPC (Windows), sharing a single HTTP/2 keep-alive pool, token state, and SQLite WAL writer across multiple TUI windows and CLI calls (`0ms` TUI bootstrap + `<5ms` daemon-warm CLI reads + resilient automatic fallback to in-process sync if stopped).
- **Strict RSS & Cache Bounds**: Enforces an 8 MiB heap byte budget (`MAX_IMAGE_CACHE_BYTES`) across inline terminal image preview caches, trims inactive OneNote previews on tab switch, switches sync channel events to summary-only mail payloads, and runs `PRAGMA shrink_memory` on writer + pooled reader connections when transitioning to idle.
