# v0.1.0 — Initial Pure Microsoft Outlook Release (`@bitefoundry/outlook`)

Version `0.1.0` launches **`outlook`** (`@bitefoundry/outlook`), a standalone pure **Microsoft Outlook** terminal client and AI agent toolkit built in Rust on Microsoft Graph v1.0, local SQLite WAL + FTS5 caching, and Minimal-Chrome terminal UX.

## Highlights

- **100% Pure Microsoft Outlook (Mail, Calendar, Tasks, Contacts)**:
  - **Mail**: Header-first folder listing and incremental delta sync (`MAIL_HEADER_SELECT_FIELDS`), on-demand HTML body hydration and neighbor prefetch, conversation thread grouping (`t`), Focused/Other Inbox toggle (`F`), quoted-reply folding (`z`), Markdown-to-HTML compose/reply/reply-all/forward, archive/mark-read/flag/move/delete with 0ms optimistic UI & automatic rollback, and offline FTS5 + `LIKE` search.
  - **Calendar**: Agenda and time-window event queries (`calendarView`), event creation with Teams online meeting support, RSVP actions (`accept`, `tentative`, `decline`), and event cancellation.
  - **Tasks (Microsoft To Do)**: Task lists, task creation, due dates & importance, and instant completion toggling (`0ms` optimistic UI).
  - **Contacts & Directory**: Unified personal Outlook contacts (`/me/contacts`) and Entra ID organization directory (`/users`) search, creation, and management.
- **Minimal-Chrome Responsive TUI (`ratatui`)**:
  - 3-tier responsive layout (`Wide >= 120`, `Medium 80..119`, `Narrow < 80`) across tabs `1` Mail, `2` Calendar, and `3` Tasks & Contacts.
  - Unified `Ctrl+K` Omni-Switcher, Vim/Gmail triage shortcuts (`j/k`, `r/R/f/c`, `e/u/g/m`, `z`), multi-protocol inline terminal image preview (`v` / `Alt+v` / click across **Kitty**, **iTerm2 `OSC 1337`**, **Sixel**, and **24-bit Unicode Half-Blocks**), and colorblind-safe themes (`NO_COLOR`, `Ansi16`, `Ansi256`, Midnight Dark, Daylight Light).
- **Zero-Config Authentication & M365 Shared-Session Bootstrap**:
  - Interactive PKCE loopback login (`outlook login`), headless Device Code flow (`--device-code`), external token brokers (`OUTLOOK_TOKEN_FILE` / `OUTLOOK_TOKEN_REFRESH_CMD`), and automatic read-only M365 shared-session bootstrap from `TEAMS_TOKEN_FILE` or `teams-cli` (`OUTLOOK_SHARE_M365_AUTH=true`).
- **AI Agent Toolkits (`outlook serve` & `outlook mcp`)**:
  - Local Axum HTTP JSON API on `127.0.0.1:3939` with OpenAPI 3.1 contract (`/openapi.json`) and optional Bearer `--token` auth.
  - Stdio newline-delimited JSON-RPC 2.0 MCP server (`outlook mcp`) exposing 20 Outlook tools for Claude Desktop, Claude Code, and Codex.
- **Background Sync Daemon & Native Packaging**:
  - Single-instance background sync daemon (`outlook daemon start | status | stop | restart`) over `0600` Unix Domain Sockets or authenticated loopback IPC (`OUTLOOK_AUTO_DAEMON=1`).
  - Cross-platform `@bitefoundry/outlook` npm distribution (`win32-x64`, `win32-arm64`, `darwin-x64`, `darwin-arm64`, `linux-x64`, `linux-arm64`) with zero-Node-startup `postinstall.mjs` linking, `GLIBC 2.28` Linux compatibility (`AlmaLinux 8` verified), and SHA-256 verified self-updates (`outlook update`).
