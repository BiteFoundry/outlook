## What's Changed

### Terminal Image Preview Quality & Protocol Detection
- Replaced fixed low-resolution downsampling and distorted aspect-ratio scaling with terminal cell-geometry sizing and unified protocol detection across Kitty, iTerm2, Sixel, and half-block renderers.

### Native HTML/SVG/Canvas & Embedded Graphics Rendering
- Eliminated raw HTML/SVG/script source leaks in mail HTML rendering and HTML preview overlays via pure-Rust `bitefoundry-html` (`resvg 0.50` + `tiny-skia` + `base64`) for inline `<svg>`, `<canvas>`, and `data:image/*` graphics, with an explicit `[o: Browser]` banner for external `<script src>` content.

### Unified Markdown Rendering & `.md` Preview
- Standardized Markdown rendering and outbound conversion on `pulldown-cmark 0.13` via `bitefoundry-html::markdown` and enabled direct `.md` attachment previewing.

### Width-Aware Text Wrapping & Plain-Text Newline Preservation
- Migrated mail reading panes, headers, tables, calendar details, and To Do views to display-width-aware styled wrapping (`wrap_styled_spans` / `render_wrapped_table`) and preserved explicit `\n` breaks in plain-text emails.

### TUI Mouse, Compose & Sync Reliability
- Fixed right-click row targeting, compose draft preservation, calendar event form interaction, and sync rollback handling, and added Docker / MCP Registry (`server.json`) packaging.
