# v0.4.0 — Performance Overhaul, AlmaLinux 8 (GLIBC 2.28) Support & External Token Brokers

Version `0.4.0` delivers a major TUI/SQLite/sync responsiveness overhaul, prebuilt **AlmaLinux 8 / RHEL 8+ (`GLIBC 2.28`)** Linux binaries, first-class external token broker integration (`TEAMS_TOKEN_FILE` / `TEAMS_TOKEN_REFRESH_CMD`), and cross-persona CLI unification.

## TUI & Sync Responsiveness

- **Dirty-driven rendering & burst event coalescing**: Eliminates unconditional 200ms idle redraws and mouse-hover redraw storms, coalescing up to 64 rapid scroll/typing/sync events per frame and wrapping draws in synchronized terminal updates (`BeginSynchronizedUpdate` / `EndSynchronizedUpdate`) for flicker-free SSH/Linux sessions.
- **HTML DOM & viewport line caching**: Memoizes `scraper` HTML fragment parsing and caches built `RenderedLine` buffers across `chat_view`, `thread_view`, and `outlook_view`, turning scrolling and composer typing into sub-millisecond operations.
- **SQLite WAL reader pool & zero-churn polling**: Separates a dedicated read-only WAL connection pool (`readers`) from the writer connection so UI reads never block behind background sync writes, switches hot paths to `prepare_cached`, and skips redundant `UPDATE` + `FTS5` trigram re-tokenization when polled items are unchanged.
- **Two-lane async sync engine & low-latency HTTP**: Splits active focus/interactive commands onto a dedicated fast lane (never blocked by slow background Outlook/OneNote polls), parallelizes bootstrap Graph requests with `tokio::join!`, offloads `drafts.json` writes to `spawn_blocking` only when changed, and enables `tcp_nodelay` + connection pool keep-alive tuning.

## Linux & AlmaLinux 8 (`GLIBC 2.28`) Support

- **`cargo-zigbuild` `GLIBC 2.28` release targets**: Prebuilt `x86_64-unknown-linux-gnu` and `aarch64-unknown-linux-gnu` binaries now target `GLIBC 2.28` (`AlmaLinux 8`, `RHEL 8+`, `Rocky Linux 8+`, `Ubuntu 20.04+`, `Debian 10+`), verified in CI via `scripts/verify-glibc.mjs --max 2.28` and an `almalinux:8` container smoke test.
- **Headless / SSH / Wayland hardening**: Prevents 25-second synchronous D-Bus Secret Service hangs on headless Linux via socket pre-checks + 800ms bounded keyring ops (`0600` `credentials.json` fallback), retains persistent X11/Wayland clipboard ownership, and adds `wl-copy`/`wl-paste`/`xclip`/`xsel` plus **OSC 52** terminal clipboard fallback over SSH/tmux.

## External Token Brokers & CLI Ergonomics

- **`TEAMS_TOKEN_FILE` & `TEAMS_TOKEN_REFRESH_CMD` (`token_file` / `token_refresh_cmd` in `config.toml`)**: Reads raw JWT files (e.g. `tc-auth` `~/.cursor/tc-auth/access_token`) or OAuth/Azure CLI JSON (`access_token` / `accessToken`) directly on demand without shell wrapper truncation issues, automatically running the refresh command hook when within `TEAMS_TOKEN_REFRESH_MINS` (default 5 min) of `exp` or on HTTP `401`.
- **Automatic keyring skip & explicit expiry diagnostics**: Automatically skips OS keyring access when `TEAMS_TOKEN_FILE` or `TEAMS_ACCESS_TOKEN` is active, extracts `oid`/`name`/`upn`/`exp` directly from JWT claims, and reports explicit expiry timestamps (`Token expired (exp: YYYY-MM-DD HH:MM)`) instead of silently printing `- (-)` in `whoami`.
- **Cross-persona CLI unification & `--top` alias**: Supports `outlook mail <subcmd>` (`outlook mail list`), `teams inbox`, and `onenote notes <subcmd>` uniformly across personas, adds `--top` as a visible alias for `--limit` on all list/search commands, and documents key `TEAMS_*` environment variables directly in `--help`.
