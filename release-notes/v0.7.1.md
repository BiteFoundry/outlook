# v0.7.1 — Quiet Background Polling, TUI Performance & Storage/Security Hardening

Version `0.7.1` focuses on **quiet, resilient background syncing**, **low-CPU/zero-copy TUI rendering**, **SQLite/FTS5 & Microsoft Graph efficiency**, and **CLI/HTTP/updater security hardening**.

## Quiet Background Polling & Tiny Transient-Error Spinner

- **Zero Error Toast Spam on Passive Polls**: Passive background polls (`2.5s` active room poll, `8s` chat list poll, `30s` presence poll, focus-change auto-sync, and passive older-history autoload) never emit `ToastKind::Error` popups on transient failures.
- **1-Cell Status-Bar Retry Spinner**: During transient network, `429`, or `5xx` retries (`POLL_RETRY_SUMMARY`), the status bar displays only a subtle 1-cell Braille spinner (`⠋..⠏`) in the theme warning color with no intrusive error text, immediately reverting to `✓ Synced` (`0 Hz` idle redraw) once healthy.
- **Silent `403` Circuit-Breakers & Channel Delta Fallback**: Automatically trips per-token `Presence.Read.All` (`403`) circuit-breakers and restricted chat/channel `403` fast-lane tracking without noisy retries, and fixes channel delta sync fallback handling.
- **Exponential Backoff with Jitter & Zero-Change Broadcast Suppression**: Applies exponential backoff with jitter on repeated transient errors and suppresses redundant `CoreEvent` / UI broadcasts when polled state has not changed.

## TUI Rendering, Memory & UX Optimizations

- **`0 Hz` Idle Loop & `0 ms` Non-Blocking `PasteBurstDetector`**: Eliminates idle frame redraws when no spinner or toast transition is active, and detects unbracketed multiline pastes without adding input latency.
- **Viewport-Decoupled Selection & Zero-Copy `Arc<[RichBlock]>` Parser Cache**: Decouples `O(viewport)` selection highlighting from `CHAT_LINES_CACHE` and `THREAD_LINES_CACHE`, and shares `Arc<[RichBlock]>` slices directly from `HTML_PARSE_CACHE` (LRU HTML & Adaptive Card cache) without cloning cached block trees.
- **Faster Room Open & Smarter Layout**: Removes redundant triple Graph fetches when opening a room, fixes Wide-mode thread composer mouse click hit-testing, fixes soft-wrap composer height and cursor tracking, restores direct buttons in the Narrow top bar, fixes CJK display-width padding, and caps/caches `ImagePreview` errors (`64` entries).

## SQLite, FTS5, Graph, Auth, CLI & Security Hardening

- **SQLite & FTS5 Throughput**: Returns true changed-row counts from `upsert_messages`, uses an `O(1)` FTS5 insert path for newly inserted messages, and adds an indexed `has_mentions` column (`idx_messages_has_mentions`, schema `user_version` `52`/`53`) with SQL `LIMIT` pushdown for Activity queries.
- **Auth & Graph Efficiency**: Adds `(mtime, len)` external token caching with lock-free OAuth refresh handling, single-flight Graph `/me` resolution, unsupported `$orderby` memoization, and streaming media downloads.
- **Lean Dependencies & Async Offloading**: Trims `Cargo.toml` feature sets (`http2`, `gzip`, `lto = "fat"`) and offloads SQLite operations onto `tokio::task::spawn_blocking` across `sync`, `serve`, and `mcp`.
- **CLI & Network Security**: Enforces an authentication guard on non-loopback `--bind` HTTP server addresses, strips `Authorization: Bearer` headers on external `contentUrl` fetches, and mandates `SHA256SUMS.txt` checksum verification in `teams update`.
