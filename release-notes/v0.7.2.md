# v0.7.2 — Multi-Protocol High-Resolution Terminal Graphics & Synchronized TUI Image Preview

Version `0.7.2` brings **crisp, pixel-accurate terminal image rendering** across Windows, Linux, and macOS via **Kitty**, **iTerm2**, **pure-Rust Sixel**, and **24-bit Unicode Half-Block** protocols, paired with a **flicker-free synchronized TUI preview overlay** and **instant offline zoom/protocol switching**.

## Multi-Protocol High-Resolution Terminal Graphics (Windows, Linux & macOS)

- **Automatic Capability Detection & Routing**: Automatically selects the highest-fidelity terminal graphics protocol from environment/terminal hints without issuing blocking terminal queries:
  - **Kitty Graphics Protocol** (`\x1b_G...`): Native pixel rendering on Kitty and Ghostty, with `q=2` response suppression and clean fixed-ID (`i=4242`) placement deletion.
  - **iTerm2 Inline Images (`OSC 1337`)**: Native high-DPI inline rendering on WezTerm (Windows/Linux/macOS), iTerm2 (macOS), Rio, Mintty, and Hyper with `doNotMoveCursor=1` TUI placement safety.
  - **Pure-Rust Sixel (`DCS q`)**: Self-contained 256-color median-cut quantizer with RLE compression and background alpha compositing for Windows Terminal v1.22+, foot, Contour, and mlterm — zero native C dependencies, preserving `GLIBC 2.28` compatibility on Linux builds.
  - **24-Bit Unicode Half-Blocks (`▀`)**: Universal truecolor fallback for `tmux`/`screen`, legacy terminals, and 60fps scroll-safe inline chat thumbnails.

## Synchronized TUI Pixel Image Preview & Instant Offline Re-Encoding

- **Synchronized Post-`ratatui` Pixel Rendering**: Wraps `ImagePreview` (`v` / click) frame updates in `BeginSynchronizedUpdate`..`EndSynchronizedUpdate`, marks active pixel rectangles with `Buffer::cell_mut(...).set_skip(true)` so `ratatui` diffs never overwrite rendered pixels, and guarantees artifact-free cleanup on zoom, navigation, terminal resize, external editor launch, and close.
- **Instant Offline Zoom & Live Protocol Switching**: Adds a bounded raw attachment byte cache (`8` entries / `16 MiB`) alongside protocol-aware rendered cache keys, enabling instantaneous `+`/`-`/`0`/mouse-wheel zoom (`25%..=200%`), `[`/`]` cycling, and live `p` protocol switching (`[Kitty]` / `[iTerm2]` / `[Sixel]` / `[Halfblock]`) with zero repeated Microsoft Graph downloads.

## Configuration, CLI `--protocol` Flag & `teams doctor` Diagnostics

- **Config & Environment Overrides**: Adds `image_protocol = "auto"` (`auto | kitty | iterm2 | sixel | halfblock`) in `config.toml`, plus `TEAMS_IMAGE_PROTOCOL` and `TEAMS_CELL_PIXEL_SIZE` environment overrides.
- **CLI & Diagnostics**: Adds `--protocol <auto|kitty|iterm2|sixel|halfblock>` to `teams preview` and `teams preview-file`, and reports detected `image_protocol`, `image_protocol_preference`, and `cell_px` dimensions in `teams doctor` (both human-readable and `--json` output).
