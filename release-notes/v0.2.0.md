### Compatibility Changes

- **JSON responses are compact by default** for `read --json`, `mail --json`, `event --json`, and MCP `get_message` / `list_messages`, with `omitted` metadata and follow-up `hint` on detail reads.
  Migration: pass `--json --full` in the CLI (e.g. `outlook read <MESSAGE_ID> --json --full`, `outlook mail --json --full`, `outlook event <EVENT_ID> --json --full`) or `"compact": false` in MCP.
- **Attachment Base64 bytes (`content_bytes_b64`) are removed from CLI and MCP JSON outputs** and replaced with a `content_cached` boolean on attachment metadata.
  Migration: download bytes with `outlook download <MESSAGE_ID> --attachment <ATTACHMENT_ID> --dir <DIR> --json` (add `--offline` for cached bytes) or MCP `download_attachment`.
- **Folder and To Do list JSON responses default to 50 items** with `returned`, `has_more`, and `next_cursor` pagination (`folders --json`, `task-lists --json`, MCP `list_mail_folders`, `list_todo_lists`).
  Migration: pass `--limit 1000` (e.g. `outlook folders --json --limit 1000`) or follow `--cursor <NEXT_CURSOR>` / MCP `cursor`.
- **Remote mail search no longer stops at a fixed 100-item (2-page) cap** (`search --remote`, MCP `search_mail`) and now follows pages up to the requested `limit` with `next_cursor` continuation.
  Migration: pass an explicit `--limit <N>` (e.g. `outlook search <QUERY> --remote --limit 50 --json`) or MCP `limit` and continue with `next_cursor`.
