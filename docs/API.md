# `outlook` HTTP JSON API

Local HTTP/JSON server for AI agents, scripts, and integrations. Exposed by `outlook serve` (alias `api`), backed by Microsoft Graph v1.0, local SQLite WAL/FTS5 caching, and the background sync engine (`sync::spawn_sync_engine`).

## Starting the server

```bash
outlook serve                         # http://127.0.0.1:3939
outlook serve --port 9000             # custom port
outlook serve --bind 127.0.0.1 --port 3939
outlook serve --api-key secret123     # require Bearer secret123 or x-api-key: secret123
outlook serve --token secret123       # --token is an alias for --api-key
outlook api                           # alias for `serve`
```

- `--bind` defaults to `127.0.0.1` (loopback only). Binding to a non-loopback address (e.g. `0.0.0.0`) requires `--api-key <KEY>` (or `--token <KEY>`) unless `OUTLOOK_ALLOW_INSECURE_SERVE=1` is explicitly set.
- `--port` defaults to `3939`.
- `--api-key` (alias `--token`) is optional; when set, every endpoint except `GET /health` requires either `Authorization: Bearer <key>` or `x-api-key: <key>`.
- Requires an existing login (`outlook login`), `OUTLOOK_ACCESS_TOKEN`, `OUTLOOK_TOKEN_FILE`, or a shared M365 session (`teams-cli` / `TEAMS_TOKEN_FILE` when `OUTLOOK_SHARE_M365_AUTH=true`).
- On startup, `outlook serve` spawns the background sync engine so the local SQLite cache stays warm while serving requests.

## Conventions

- All responses are JSON (`Content-Type: application/json`).
- Errors use `{"error": "<message>"}` with HTTP `400`, `401`, `403`, `404`, or `500`.
- `limit` is clamped to `1..=1000`.
- Mail folder parameters accept a folder ID, display name/prefix, or well-known alias (`inbox`, `sent`, `drafts`, `archive`, `trash`, `junk`).
- To Do list parameters default to `"tasks"` and accept a list ID, display name, or `"default"` / `"tasks"` / `"defaultList"`.
- CORS is restricted to loopback (`localhost` / `127.0.0.1` / `[::1]`) origins when `--api-key` is unset, and permissive when `--api-key` is configured.

## Endpoints

### System & Auth

#### `GET /health`

Always public, even when `--api-key` is configured.

```bash
curl http://127.0.0.1:3939/health
```

```json
{
  "ok": true,
  "user_id": "00000000-0000-0000-0000-000000000000",
  "version": "0.1.0"
}
```

#### `GET /openapi.json`

Returns the OpenAPI 3.1.0 specification JSON generated by the running server.

```bash
curl http://127.0.0.1:3939/openapi.json
```

#### `GET /v1/whoami`

Returns the active user profile, auth mode/source (`outlook-cli` vs shared `teams-cli` session), token expiry, and JWT `scp` / `roles` diagnostics.

```bash
curl http://127.0.0.1:3939/v1/whoami -H "Authorization: Bearer secret123"
```

```json
{
  "authenticated": true,
  "user_id": "00000000-0000-0000-0000-000000000000",
  "display_name": "Alice Kim",
  "email": "alice@contoso.com",
  "client_id": "14d82eec-204b-4c2f-b7e8-296a70dab67e",
  "tenant_id": "common",
  "auth_mode": "pkce",
  "auth_source": "keyring",
  "expires_at": 1795023600,
  "expired": false,
  "scopes": ["Mail.ReadWrite", "Mail.Send", "Calendars.ReadWrite", "Tasks.ReadWrite", "Contacts.Read"],
  "roles": []
}
```

### Mail

#### `GET /v1/mail/folders?refresh=false&offline=false`

Lists Outlook mail folders with unread and total item counts.

```bash
curl "http://127.0.0.1:3939/v1/mail/folders?refresh=true"
```

```json
{
  "folders": [
    {
      "id": "AAMkAGI2...",
      "display_name": "Inbox",
      "well_known_name": "inbox",
      "parent_folder_id": null,
      "child_folder_count": 0,
      "unread_item_count": 4,
      "total_item_count": 128
    }
  ]
}
```

#### `GET /v1/mail/messages?folder=inbox&limit=30&unread=false&flagged=false&focused=false&refresh=false&offline=false`

Lists messages in a mail folder (`inbox`, `sent`, `drafts`, `archive`, `trash`, `junk`, folder name, or folder ID).

```bash
curl "http://127.0.0.1:3939/v1/mail/messages?folder=inbox&limit=20&unread=true"
```

```json
{
  "folder": { "id": "AAMkAGI2...", "display_name": "Inbox", "well_known_name": "inbox" },
  "messages": [
    {
      "id": "AAMkAGI2...",
      "conversation_id": "AAQkAGI2...",
      "folder_id": "AAMkAGI2...",
      "subject": "Quarterly Review",
      "from": { "name": "Bob Smith", "address": "bob@contoso.com" },
      "received_at": "2026-11-18T09:30:00Z",
      "is_read": false,
      "flagged": false,
      "importance": "normal",
      "inference_classification": "focused",
      "has_attachments": true,
      "body_loaded": false,
      "preview": "Attached are the Q4 numbers..."
    }
  ]
}
```

#### `GET /v1/mail/messages/{id}?offline=false`

Fetches full headers, HTML/plain body, and attachment metadata for a single message (and caches it in SQLite).

```bash
curl "http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2..."
```

#### `POST /v1/mail/send`

Composes and sends a new email (Markdown compiled to HTML) with optional `cc`, `bcc`, `importance` (`low` | `normal` | `high`), host file `attachments`, and `save_to_sent_items` (default `true`). `markdown` also accepts alias `body`.

```bash
curl -X POST http://127.0.0.1:3939/v1/mail/send \
  -H "Content-Type: application/json" \
  -d '{"to":["bob@contoso.com"],"subject":"Release v0.1.0","markdown":"Build **passed**!","importance":"high"}'
```

```json
{
  "ok": true,
  "to": ["bob@contoso.com"],
  "subject": "Release v0.1.0"
}
```

#### `POST /v1/mail/messages/{id}/reply`

Replies (`reply_all: false`) or replies-all (`reply_all: true`) to an email message. `markdown` also accepts alias `body`.

```bash
curl -X POST http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2.../reply \
  -H "Content-Type: application/json" \
  -d '{"markdown":"Looks good, approved.","reply_all":true}'
```

#### `POST /v1/mail/messages/{id}/forward`

Forwards an email message to one or more recipients (`to`) with an optional Markdown `markdown` (alias `comment`) preface.

```bash
curl -X POST http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2.../forward \
  -H "Content-Type: application/json" \
  -d '{"to":["carol@contoso.com"],"markdown":"FYI — see thread below."}'
```

#### `PATCH /v1/mail/messages/{id}`

Updates read status (`is_read`), flag status (`flagged`), and/or moves the message to `destination_folder_id` (alias `destination_folder`, accepting folder name, alias such as `"archive"`, or folder ID). At least one field must be provided.

```bash
curl -X PATCH http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2... \
  -H "Content-Type: application/json" \
  -d '{"is_read":true,"flagged":false,"destination_folder_id":"archive"}'
```

```json
{
  "ok": true,
  "message_id": "AAMkAGI2...",
  "is_read": true,
  "flagged": false,
  "moved": { "id": "AAMkAGI2..." }
}
```

#### `DELETE /v1/mail/messages/{id}`

Deletes a mail message and removes it from the local SQLite cache.

```bash
curl -X DELETE http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2...
```

#### `POST /v1/mail/messages/{id}/attachments/{att_id}/download`

Downloads an attachment to disk on the host running `outlook serve` (defaults to `download_dir`, usually `Downloads/outlook`). Optional body: `{"out_dir": "/path/to/dir"}` (alias `dir`).

```bash
curl -X POST http://127.0.0.1:3939/v1/mail/messages/AAMkAGI2.../attachments/ATT_ID/download \
  -H "Content-Type: application/json" \
  -d '{"out_dir":"./downloads"}'
```

```json
{
  "ok": true,
  "path": "./downloads/report.pdf",
  "file_name": "report.pdf",
  "bytes_written": 48120
}
```

#### `GET /v1/mail/search?q=...&folder=&remote=false&limit=30`

Searches local SQLite FTS5 + `LIKE` (`hits`) and, when `remote=true`, queries Microsoft Graph KQL `$search` (`remote`) while caching returned messages.

```bash
curl "http://127.0.0.1:3939/v1/mail/search?q=quarterly&remote=true&limit=20"
```

### Calendar

#### `GET /v1/calendar/events?from=&to=&days=7&limit=50&offline=false`

Lists calendar events within a time window (`from` / `to` accept aliases `start` / `end` as ISO-8601 or `YYYY-MM-DD`; defaults to now through `+7` days).

```bash
curl "http://127.0.0.1:3939/v1/calendar/events?days=14"
```

```json
{
  "start": "2026-11-18T00:00:00Z",
  "end": "2026-12-02T00:00:00Z",
  "events": [
    {
      "id": "AAMkAGI2...",
      "subject": "Architecture Review",
      "start_iso": "2026-11-20T09:00:00Z",
      "end_iso": "2026-11-20T10:00:00Z",
      "time_zone": "UTC",
      "is_all_day": false,
      "location": "Room 4B",
      "response_status": "accepted",
      "is_online_meeting": true,
      "online_meeting_url": "https://teams.microsoft.com/l/meetup-join/..."
    }
  ]
}
```

#### `POST /v1/calendar/events`

Creates a new calendar event. `start_iso` / `end_iso` accept aliases `start` / `end`; `markdown` accepts alias `body`; `is_online_meeting` accepts alias `online`.

```bash
curl -X POST http://127.0.0.1:3939/v1/calendar/events \
  -H "Content-Type: application/json" \
  -d '{"subject":"Sprint Planning","start_iso":"2026-11-20T14:00:00Z","end_iso":"2026-11-20T15:00:00Z","attendees":["bob@contoso.com"],"is_online_meeting":true}'
```

#### `GET /v1/calendar/events/{id}?offline=false`

Reads full details and attendees for a calendar event.

```bash
curl "http://127.0.0.1:3939/v1/calendar/events/AAMkAGI2..."
```

#### `POST /v1/calendar/events/{id}/rsvp`

Responds to a meeting invitation (`response`: `"accept"` | `"tentative"` | `"decline"`, optional `comment`).

```bash
curl -X POST http://127.0.0.1:3939/v1/calendar/events/AAMkAGI2.../rsvp \
  -H "Content-Type: application/json" \
  -d '{"response":"accept","comment":"See you there."}'
```

#### `DELETE /v1/calendar/events/{id}`

Cancels/deletes a calendar event and removes it from the local cache.

```bash
curl -X DELETE http://127.0.0.1:3939/v1/calendar/events/AAMkAGI2...
```

### Microsoft To Do

#### `GET /v1/todo/lists?refresh=false&offline=false`

Lists Microsoft To Do task lists.

```bash
curl "http://127.0.0.1:3939/v1/todo/lists"
```

#### `GET /v1/todo/tasks?list=tasks&all=false&limit=50&refresh=false&offline=false`

Lists tasks in a To Do list (`all` accepts alias `include_completed`).

```bash
curl "http://127.0.0.1:3939/v1/todo/tasks?list=tasks&all=true"
```

#### `POST /v1/todo/tasks`

Creates a To Do task (`body_plain` accepts alias `notes`; `due_date_iso` accepts alias `due`; `importance`: `low` | `normal` | `high`).

```bash
curl -X POST http://127.0.0.1:3939/v1/todo/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Publish outlook v0.1.0","due_date_iso":"2026-11-20","importance":"high"}'
```

#### `PATCH /v1/todo/tasks/{id}`

Marks a To Do task completed or incomplete (`{ "list"?: "tasks", "completed": true }`).

```bash
curl -X PATCH http://127.0.0.1:3939/v1/todo/tasks/TASK_ID \
  -H "Content-Type: application/json" \
  -d '{"completed":true}'
```

#### `DELETE /v1/todo/tasks/{id}?list=tasks`

Deletes a To Do task.

```bash
curl -X DELETE "http://127.0.0.1:3939/v1/todo/tasks/TASK_ID?list=tasks"
```

### Contacts & Directory

#### `GET /v1/contacts?q=&limit=50&offline=false`

Lists personal Outlook contacts (`/me/contacts`) or, when `q` (alias `query`) is provided, searches both personal contacts and the Entra ID organization directory (`/users`).

```bash
curl "http://127.0.0.1:3939/v1/contacts?q=alice&limit=20"
```
